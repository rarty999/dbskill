# YouTube 爆款文案拆解助手 · 文案版

面向 10 分钟以上长视频的省额度版本：**只分析文案，不看画面**。单文件 Web 应用，下载 `index.html` 双击即可使用。

## 与画面版（youtube-viral-breakdown）的区别

| | 画面版 | 文案版（本工具） |
|---|---|---|
| 分析对象 | 画面 + 声音 + 结构 | 仅口播文案 |
| 10 分钟视频 token 消耗 | ~18 万 | ~2-3 万（约 1/8） |
| 适合 | Shorts / 短视频 | 10 分钟以上口播类长视频 |
| 输出 | 含分镜表、画面拆解 | 文案逻辑、深度选题、口播脚本 |

## 工作流程（四步管线）

1. **获取文稿**：以最低画质、每 5 秒 1 帧读取视频，让 Gemini 只转写口播逐字稿——无论视频有没有字幕都能拿到文字（听音频转写，不依赖 YouTube 字幕）。文稿按视频 ID 缓存在本机，重复分析不再重复转写。
2. **拆解文案逻辑**：逐段结构（引用原文为证）、开头钩子、叙事框架、情绪曲线、心理触发器、一句话公式、可迁移写作规则、金句钩子库。
3. **深度选题**：9 个选题分三类（纵深挖掘 / 跨界迁移 / 反向差异化），每个选题包含核心洞察、目标人群、情绪触发、复用了哪条爆款逻辑、开头钩子文案、内容大纲、备选标题。填写「账号定位」后选题会围绕你的赛道生成。
4. **二次创作**：自动为推荐选题生成完整口播逐字稿；任意选题卡片也可一键单独生成脚本。

## 其他能力

- **直接粘贴文稿模式**：已有字幕/文案时完全跳过视频步骤，零视频 token
- **文稿缓存管理**：设置区可查看每条缓存（视频链接/时间/字数/预览）、单条删除或一键清空；删除后重新分析会重新转写。缓存存在本机浏览器 localStorage，重启电脑不丢失，清除浏览器数据会清掉，最多 12 条自动淘汰最旧
- 导出 Markdown / JSON（含全部选题、脚本和完整文稿）
- 深色模式；API Key 与画面版共用，只存本机 localStorage

## 使用前提

- 一个 Gemini API Key（[Google AI Studio](https://aistudio.google.com/apikey) 免费申请）
- 能访问 Google 服务的网络环境
- 只分析公开视频；二次创作请做原创化改编，尊重原作者版权
